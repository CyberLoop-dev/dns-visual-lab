# 🌐 DNS Visual Lab

A local learning tool for reading simple DNS zone-file records and presenting them clearly.

## ✨ Features
- Recognizes common A, AAAA, CNAME, MX, and TXT record lines.
- Groups records by type and prints a compact summary.
- Reads a local text file only; it does not query DNS servers.
- Keeps parsing intentionally small and beginner-friendly.

## 🚀 Usage
```bash
python dns_records.py examples/sample.zone
```
